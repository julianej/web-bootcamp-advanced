## 📁 Project Structure
# Web TypeScript Express.js App

A server-side rendered blog application built with **Express.js**, **TypeScript**, and **Nunjucks**. The project follows a modular architecture by separating application configuration, routing, controllers, data, and utility functions.

## 📁 Project Structure


## 🛠️ Architecture

The application uses a modular MVC-inspired architecture.

### `src/` – Application Source Code

Contains all TypeScript files.

| File | Responsibility |
|---|---|
| `app.ts` | Initializes Express, configures Nunjucks, serves static files, and mounts the router. |
| `routes/index.ts` | Defines application routes and connects URLs to controller functions. |
| `controllers/postController.ts` | Handles HTTP requests, retrieves post data, applies filtering and pagination, and renders templates. |
| `data/posts.ts` | Stores and exports the blog post data. |
| `utils/helpers.ts` | Contains reusable helper functions, such as date formatting or other utility logic. |

### `views/` – Nunjucks Templates

Contains the HTML templates rendered on the server.

| File | Responsibility |
|---|---|
| `index.html` | Displays the blog overview with posts, filters, and pagination. |
| `post.html` | Displays an individual blog post. |

### `public/` – Static Assets

Contains files served directly to the browser.

- `assets/` – Images and other media files.
- `css/` – Stylesheets for the application.

### `dist/` – Compiled JavaScript

Contains the JavaScript output generated by the TypeScript compiler.

The TypeScript source files in `src/` are compiled into JavaScript files in `dist/`.

### Configuration Files

| File | Responsibility |
|---|---|
| `package.json` | Defines project metadata, dependencies, and npm scripts. |
| `tsconfig.json` | Configures the TypeScript compiler, including source and output directories. |

## 🔄 Request Flow

When a user visits the blog, the request follows this flow:

1. **Client:** The browser sends an HTTP request.
2. **App:** Express receives the request in `app.ts`.
3. **Router:** `routes/index.ts` matches the URL to a route.
4. **Controller:** `postController.ts` handles the request.
5. **Data:** The controller retrieves the required posts from `data/posts.ts`.
6. **View:** Nunjucks renders the appropriate HTML template.
7. **Response:** Express sends the rendered HTML back to the browser.

```text
Browser
   │
   ▼
app.ts
   │
   ▼
routes/index.ts
   │
   ▼
controllers/postController.ts
   │
   ├──────────────► data/posts.ts
   │
   ├──────────────► utils/helpers.ts
   │
   ▼
views/
   │
   ▼
Rendered HTML
   │
   ▼
Browser
```
